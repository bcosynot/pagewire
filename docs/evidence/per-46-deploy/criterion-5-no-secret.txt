=== Criterion 5 — no new plaintext secret is added to flake.nix ===

Two halves: the flake must not carry a secret, and the file that DOES carry one must be
locked down.

-------------------------------------------------------------------------------
1. The box's flake.nix carries no token — it references the file by PATH only
-------------------------------------------------------------------------------
    $ grep -nE 'PAGEWIRE_[A-Z_]*TOKEN|Bearer|token *=' /root/base-server-lxc/flake.nix
    (no matches)

    $ grep -n environmentFile /root/base-server-lxc/flake.nix
    424:              environmentFile = "/var/app/data/pagewire/pagewire.env";

The pagewire addition to the flake is three things and nothing else: the input by URL,
the module import, and the path. The module's own comment says why:

    # Referenced by path, never inlined — AGENTS.md forbids new plaintext
    # secrets in this flake, and criterion 5 of PER-46 checks the diff.

-------------------------------------------------------------------------------
2. The relay's own repo never carries a secret either
-------------------------------------------------------------------------------
    $ git grep -n 'TOKEN=' -- deploy/
    deploy/pagewire.env.example:30:PAGEWIRE_TOKEN=REPLACE_WITH_THE_DEVICE_SHARED_SECRET
    deploy/pagewire.env.example:46:PAGEWIRE_READWISE_TOKEN=REPLACE_WITH_A_READWISE_TOKEN
    deploy/pagewire.env.example:53:PAGEWIRE_HARDCOVER_TOKEN=REPLACE_WITH_A_HARDCOVER_TOKEN

Only placeholders. The real value exists in exactly two places, both outside version
control: `spike/plugin/token.json` (git-ignored, copied to the SD card by `make deploy`)
and the installed env file below.

-------------------------------------------------------------------------------
3. The file that holds the token is mode 600 and owned by the service user
-------------------------------------------------------------------------------
    $ ls -l /var/app/data/pagewire/pagewire.env
    -rw------- 1 pagewire pagewire 4889 Nov  2 18:38 /var/app/data/pagewire/pagewire.env

    $ ls -ld /var/app/data/pagewire
    drwxr-x--- 2 pagewire pagewire 4096 … /var/app/data/pagewire

The token was transferred by base64 over stdin and verified by comparing the sha256 of
the token on both sides — not by reading it back and eyeballing it.

**Criterion 5 is MET.**
